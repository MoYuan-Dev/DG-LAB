三种连接方式怎么用含 WebSocket 连接步骤

① 蓝牙直连（最直接）
安卓 Chrome / iPhone Bluefy 打开本页 → 「设备」页卡片选「蓝牙直连」 → 点连接 → 弹窗选 47L121000（郊狼）/ 47L127000（负鼠）。
要求：手机浏览器支持 Web Bluetooth；先完全退出官方 App。

② 官方 App（WebSocket）—— 只要联网就能用
1. 「设备」页 → 官方 App 连接 → 点「连接」（默认中继 wss://trex.dungeon-lab.cn/v4）。
2. 等状态变成「已连中继 · 等待官方 App 配对」，页面出现二维码。
3. 打开 DG-LAB 4 官方 App → 用 App 的扫码配对扫这个二维码；同一台手机上可直接点页面里的「同一台手机上，点这里直接配对」。
4. App 里会显示已接入；回到本页，等设备标签出现（郊狼/负鼠）→ 点选设备即可控制。
连不上时点卡片上的「诊断」，会逐个探测中继并显示结果与关闭代码。

③ 服务器桥接（电脑蓝牙）
1. 电脑双击 start.bat（窗口出现「BLE 桥接已就绪」）。
2. 手机打开电脑给的地址 → 「设备」页卡片选「服务器桥接」 → 连接。
要求：电脑带蓝牙、设备在电脑 10 米内、手机与电脑同一 WiFi。

远程控制（房间码）
需要一台运行 start.bat 的电脑做中继：两台手机打开同一地址 → 一端「受控端」、一端「控制端」，输入相同房间码。
纯静态托管（GitHub Pages）没有中继，此时在「中继地址」里填 wss://电脑IP:端口/ws；或者直接用官方 App 模式做跨设备控制。

iPhone / iPad 使用说明只用手机就能玩

1. 安装 Bluefy：App Store 免费下载「Bluefy - Web BLE Browser」。Safari 不支持蓝牙，Bluefy 是 iPhone 上连接设备的浏览器。

2. 打开本页面：用 Bluefy 打开本页面地址（详见 README 的「手机版部署」：GitHub Pages 一键托管，或 a-Shell 在手机本地架服务器）。

3. 连接设备：设备开机、退出官方 App → 点「连接郊狼 / 连接负鼠」→ 系统弹窗选设备即可。

4. 添加到主屏幕：Bluefy 菜单中选择「添加到主屏幕」，之后像 App 一样一键打开。

注意：iPhone 上「麦克风」模式可能受 Bluefy 限制；远程控制需要两台手机 + 一台运行本服务器的电脑。

安全提示：请从低强度开始缓慢升高；电极请勿贴在胸口 / 颈部 / 头部；佩戴心脏起搏器、孕期、皮肤破损或对电流敏感者请勿使用。
断开连接或关闭本页面时设备输出会立即停止。使用前请先关闭 DG-LAB 官方 App，避免蓝牙占用。
